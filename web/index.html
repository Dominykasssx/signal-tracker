Signal Finder

Install the turntable firmware on an ESP8266 or ESP32 straight from your browser. Nothing to install except, on some boards, a USB driver.

Not sure which ESP32 board you have? Any board with the same chip works. The installer reads the chip and stops if it doesn't match.

2Connect and install

Plug the board in with a USB data cable, click Install and choose its serial port.

This browser can't open USB serial ports. Use Chrome or Edge on a desktop computer. Installing only works when this page is served over HTTPS.
  • No port in the list? Try another cable (many are charge-only) and install the driver for your board's USB chip (CH340 or CP210x).
  • ESP32 won't connect? Hold BOOT, tap RESET, release BOOT, then click Install again.
  • After installing, press RESET (or replug) so the new firmware starts.

4Send angles

Open any serial terminal at 115200 baud with newline line endings (Arduino Serial Monitor, pio device monitor, PuTTY, a script) and send one command per line.

SendDoesReply
90Turn to 90° (any whole number 0–270)MOVING 135 -> 90, then AT 90 once it has stopped
s10Speed in ms per degree (3–1000, default 15)SPEED 10
?StatusPOS 90 TARGET 90 SPEED 15

When automating a sweep, wait for AT before reading the signal: it's sent 300 ms after the platform stops moving.
